What is Ailuradix?

Ailuradix is the front door — a single, permanent address that always knows where everything else lives. Instead of hunting through bookmarks or remembering which file is which, you land here first and get routed anywhere in one click.

The name is built to last: as new destinations get added, they show up on this page — the address itself never changes.

Think of it less like a website and more like a front desk for everything you've built.

BillMinder

Desktop billing reminder app for macOS

The purpose of BillMinder is to help users organize recurring bills, due dates, payment status, reminders, schedules, and optional Google Calendar bill reminder events from a desktop app.

Version 0.1.0 · macOS app

Purpose of the BillMinder app

BillMinder is the same app name used on the Google OAuth consent screen. The app exists to help people keep billing obligations in one organized place. Users can add bills, review upcoming payment dates, track whether payments are paid or outstanding, receive desktop reminders, and choose to create bill reminder events in Google Calendar.

The Google Calendar connection is optional. When a user chooses to connect it, BillMinder uses Calendar access only to create, update, and delete all-day reminder events for unpaid bills.

Install

  1. Download the zip file.
  2. Open the downloaded file.
  3. Drag BillMinder into your Applications folder.
  4. Open BillMinder from Applications.

Mac Security Note

If macOS asks for confirmation the first time you open the app, use System Settings > Privacy & Security to allow BillMinder.
